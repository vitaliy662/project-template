# Спецификация: Авторизация (T-001)

## 🧪 Сценарий: вход по email/паролю
1. Открыть `/login`  
2. Ввести email и пароль  
3. Система проверяет  
4. Выдаёт JWT или ошибку

## 📦 API

### `POST /api/auth/login`
- **Вход:** `{ "email": "...", "password": "..." }`
- **Выход (200):** `{ "token": "jwt" }`
- **Ошибки:** `401` — неверные данные

## 🧩 Модели данных
### User
| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| id | uuid | ✅ | Идентификатор |
| email | string | ✅ | Уникальный |
| passwordHash | string | ✅ | bcrypt |

## ✅ Критерии приёмки
- [ ] JWT действует 1 час  
- [ ] Тесты покрывают сценарии
